# 1. Bare advisory ID (legacy, advisory-only): a line holding exactly one GHSA
#    id. A finding is allowed in any audited project when every advisory in its
#    `via` list is a listed id. Use only when the advisory has no package,
#    version, node, or project scope.
#
# 2. Scoped, self-expiring exception (preferred): a single `allow` directive
#    line, with a short justification comment above it. Every field must match
#    the finding exactly or the finding still fails:
#
#      allow ids=<GHSA,...> package=<name> version=<version> nodes=<node-path,...> projects=<project-dir,...> expires=<YYYY-MM-DD>
#
#    - ids      every `via` advisory id must be listed here
#    - package  exact npm package name (the finding name and every via[].name)
#    - version  exact installed version, read from the project lockfile per node
#    - nodes    every reported node path must be listed here (a copy on any
#               other path, bundled or not, still fails)
#    - projects every audited project dir this exception may apply to
#    - expires  UTC date; the entry is ignored on or after this date, so the
#               gate fails again and the exception must be revisited
#
